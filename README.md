# 🏨 Hotel Booking Application

A Full-Stack Hotel Booking Web Application built using **React.js** (Frontend) and **Spring Boot** (Backend).

This project allows users to browse hotels by location, view room details, and book rooms through a modern and responsive interface.

---

## 🚀 Project Overview

The Hotel Booking Application is designed to simulate a real-world hotel reservation system.  
It demonstrates full-stack development skills including:

- REST API integration
- Frontend & Backend communication
- User authentication flow
- Clean UI design
- Deployment workflow using GitHub

This project is developed for learning, portfolio, and resume purposes.

## ⚙️ How To Run Locally

### 1️⃣ Clone the Repository

```
git clone https://github.com/saiabhinav-07/hotel-booking-app.git
cd hotel-booking-app
```

---

### 2️⃣ Start Backend

```
cd hotel
./mvnw spring-boot:run
```

Backend will run on:
```
http://localhost:8080
```

---

### 3️⃣ Start Frontend

```
cd frontend
npm install
npm start
```

Frontend will run on:
```
http://localhost:3000
```
